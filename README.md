# Supply Chain Analytics & Optimization using Python

An end-to-end supply chain analytics project using Python to analyze sales, profitability, customer behavior, product performance, geographic trends, logistics efficiency, and operational risks.

## 📌 Project Overview

This project analyzes the **DataCo Smart Supply Chain Dataset**, containing **180,519 transactions and 53 attributes** across supply chain and logistics operations.

The analysis follows a complete data analytics workflow:

**Data Validation → Data Cleaning → Feature Engineering → EDA → Business Insights → Recommendations**

The objective is to transform raw transactional data into actionable insights that can support supply-chain and business decision-making.

## 🎯 Objectives

* Analyze sales and profitability performance
* Evaluate customer purchasing behavior
* Identify top-performing products and categories
* Analyze geographic and market-wise trends
* Evaluate shipping and delivery performance
* Identify operational bottlenecks and business opportunities
* Generate actionable business recommendations

## ⚙️ Feature Engineering

Several business-oriented features were engineered to extend the original dataset, including:

* **High Value Order**
* **Sales Category**
* **Profit Category**
* **Profit Margin (%)**
* **Shipping Duration**
* **Shipping Performance**

These features enable deeper analysis beyond the original dataset.

## 📊 Key Findings

The analysis found that revenue is concentrated among a relatively limited number of products, customers, and geographic markets. It also identified opportunities to reduce loss-making transactions, improve delivery performance, and strengthen operational monitoring.

> **Note:** Detailed quantitative findings and visualizations are available in the project notebook.
